# Ny - AI Travel Agent Repository

This repository contains an intelligent AI-powered travel planning application.

## Project

### AI Travel Agent
Located in `/ai-travel-agent` - A comprehensive web application for planning multi-city trips with AI-powered recommendations, visa guidance, and complete day-by-day itinerary generation.

**Features:**
- Multi-city trip planning (e.g., Dallas → Barcelona → Amsterdam)
- Visa compliance checking (Schengen visa support)
- Flight, hotel, and activity recommendations
- Day-by-day itinerary with weather forecasts
- Budget optimization with multiple options
- Direct booking links to providers

**Tech Stack:** Next.js, TypeScript, Tailwind CSS, Anthropic Claude AI

See `/ai-travel-agent/README.md` for detailed documentation and setup instructions.
