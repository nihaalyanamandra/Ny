# Core requirements for the speech delivery analytics pipeline.
# Verified installable together on Python 3.11 (2024-09 openai-whisper release).
#
# Setup:
#   python3 -m venv .venv && source .venv/bin/activate
#   pip install --upgrade pip
#   pip install "setuptools<81" wheel   # see note below
#   pip install -r requirements.txt
#
# Note on setuptools: pip builds some packages (openai-whisper) in an isolated
# build environment and grabs the latest setuptools for it. setuptools>=81
# dropped the bundled pkg_resources module, which openai-whisper's setup.py
# still imports, so the isolated build fails with
# "ModuleNotFoundError: No module named 'pkg_resources'". Installing
# "setuptools<81" into your venv first and then installing with
# --no-build-isolation avoids this:
#   pip install --no-build-isolation -r requirements.txt
#
# System dependency: ffmpeg must be on PATH (Whisper shells out to it to
# decode audio). Install via your OS package manager, e.g.:
#   macOS:  brew install ffmpeg
#   Ubuntu: sudo apt-get install ffmpeg
